## 主要功能

- 浏览热播、上新、真人剧、AI 剧和漫剧，支持剧名搜索，优先显示当前分类的作品。
- 每页显示 24 部剧集，可以向下浏览、切换上一页或下一页。
- 查看剧情介绍、演员和导演资料，点击演员可浏览相关作品。
- 「相关季数」按季数排序。
- 支持 0.5x～3.0x 播放倍速，每 0.25x 一档。
- 可在设置开启或关闭「线路优化」。
- 收藏喜欢的剧集，通过观看记录继续播放。
- 原画优先，也可以选择海外 720p 优先模式。
- 边缓存边播放、预先准备下一集，切集后自动清理已播集数的缓存。
- 支持播放／暂停、上一集／下一集、快退／快进，并可自定义跳转秒数。
- 在同一个 App 中切换简体／繁体中文与浅色／深色主题。

## 遥控器操作

| 操作 | 按键 |
| --- | --- |
| 移动和选择 | 使用方向键移动，按确认键打开 |
| 浏览更多剧集 | 向下浏览，或选择上一页／下一页 |
| 显示播放控制栏 | 播放时按确认键或上下键 |
| 快退／快进 | 控制栏隐藏时按左键／右键 |
| 返回 | 先收起控制栏，再返回上一页 |
| 调整偏好 | 在设置中选择语言、主题、跳转秒数和播放模式 |

## 剧集与版本更新

剧集列表会随片源更新，也可以在首页点击“重新整理”获取最新内容。

打开 App 时会检查版本。有新版本时，需要按照提示完成更新后才能继续使用。
