## Main features

- Related seasons listed in numerical order.
- Playback speeds from 0.5x to 3.0x in 0.25x steps.
- Turn connection optimization on or off in settings.
- Browse popular and newly added live-action dramas, AI dramas, and animated/comic-style dramas; search by title.
- Browse 24 titles per page and navigate between pages.
- Read plot summaries, cast and director information, and browse related works by actor.
- Save favorites and resume from viewing history.
- Prefer original quality or enable the overseas 720p-first mode.
- Stream while caching, prepare the next episode ahead of time, and clear cached episodes after switching.
- Play/pause, previous/next episode, rewind/fast-forward, and customize skip intervals.
- Switch between Traditional/Simplified Chinese and light/dark themes in the same app.

## Remote control

| Action | Control |
| --- | --- |
| Navigate and select | Move with the directional buttons and press OK |
| Browse more titles | Scroll down or select the previous/next page |
| Show playback controls | Press OK or Up/Down while watching |
| Rewind / fast-forward | Press Left/Right while the controls are hidden |
| Go back | Dismiss the controls first, then return to the previous screen |
| Preferences | Set language, theme, skip intervals, and playback mode in Settings |

## Content and version updates

The catalog changes as sources are updated. Use “Refresh” on the home screen to fetch the latest listings.

HGTV checks for updates when opened. If an update is required, install it to continue using the app.
