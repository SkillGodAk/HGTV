HGTV 提供繁體中文與簡體中文介面，支援亮色及暗色主題。你可以瀏覽熱門與最新劇集、搜尋、收藏、查看觀看紀錄，並在電視上使用遙控器輕鬆選劇與播放。

## 下載

最新正式版：[HGTV 0.6.0](https://github.com/SkillGodAk/HGTV/releases/tag/v0.6.0)

- 64 位元：`HGTV-0.6.0-arm64-v8a.apk`
- 32 位元：`HGTV-0.6.0-armeabi-v7a.apk`（新增）

適用於 Android 8.0 以上裝置。請依裝置支援的架構選擇 APK，下載後使用系統安裝器完成安裝即可。

## 主要功能

- 熱播、上新、真人劇、AI 劇、漫劇與搜尋
- 每頁 24 部劇集，可向下瀏覽及翻頁
- 劇情介紹、演員、導演與演員相關作品
- 收藏、觀看紀錄及續播
- 原畫優先與海外 720p 優先播放模式
- 播放、暫停、上一集、下一集、倒轉及快轉
- 自訂快轉與倒轉秒數
- 繁體中文與簡體中文切換
- 亮色與暗色主題

## 遙控器操作

| 操作 | 按鍵 |
| --- | --- |
| 移動及選擇 | 方向鍵移動，確認鍵開啟 |
| 瀏覽更多內容 | 向下移動或選擇上一頁／下一頁 |
| 顯示播放控制列 | 播放中按確認鍵或上下鍵 |
| 倒轉／快轉 | 控制列隱藏時按左鍵／右鍵 |
| 返回 | 按返回鍵收起控制列或回到上一頁 |
| 個人偏好 | 在設定調整語言、主題、跳轉秒數及播放模式 |

劇集內容會自動更新，也可以在首頁使用重新整理取得最新內容。

開啟 App 時會檢查新版本；需要更新時，依畫面提示下載並完成安裝後即可繼續使用。
