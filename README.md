<h1 align="center">HGTV</h1>
<p align="center"><strong>HONGGUO TV</strong></p>

以電視遙控器操作的 Android TV 短劇播放器。繁體中文與簡體中文可在同一個 APK 內切換。

目前正在完成首個正式版本的裝置驗證。正式下載會發布在 [Releases](https://github.com/SkillGodAk/HGTV/releases)。

## 更新方式

App 開啟時會驗證簽章版本資訊。發布強制更新後，舊版本須完成更新才能繼續進入首頁與播放。APK 會核對檔案雜湊、套件名稱、版本與安裝簽章；安裝仍需使用者在 Android 系統畫面確認。

本倉庫用於版本發布、更新資訊與使用文件。劇單及影片由內容來源提供，App 更新與劇集上新是兩件事。
