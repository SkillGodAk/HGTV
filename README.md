## 主要功能

- 瀏覽熱播、上新、真人劇、AI 劇與漫劇，支援劇名搜尋。
- 每頁 24 部劇集，可向下瀏覽與切換上一頁、下一頁。
- 查看劇情介紹、演員與導演資料，點選演員瀏覽相關作品。
- 收藏喜歡的劇集，透過觀看紀錄繼續播放。
- 原畫優先，也可選擇海外 720p 優先模式。
- 邊緩存邊播放、預先準備下一集，切集後自動清理已播集數緩存。
- 支援播放／暫停、上一集／下一集、倒轉／快轉，並可自訂跳轉秒數。
- 同一個 App 可切換繁體／簡體中文與亮色／暗色主題。

## 遙控器操作

| 操作 | 按鍵 |
| --- | --- |
| 移動與選擇 | 方向鍵移動，確認鍵開啟 |
| 瀏覽更多劇集 | 向下瀏覽，或選擇上一頁／下一頁 |
| 顯示播放控制列 | 播放中按確認鍵或上下鍵 |
| 倒轉／快轉 | 控制列隱藏時按左鍵／右鍵 |
| 返回 | 先收起控制列，再返回上一頁 |
| 調整偏好 | 在設定選擇語言、主題、跳轉秒數與播放模式 |

### 主要功能

- 浏览热播、上新、真人剧、AI 剧和漫剧，支持按剧名搜索。
- 每页显示 24 部剧集，可以向下浏览或切换上一页、下一页。

- 优先使用原画画质，也可以选择海外 720p 优先模式。

- 支持播放／暂停、上一集／下一集、快退／快进，并可自定义跳转秒数。
- 在同一个 App 中切换简体／繁体中文和浅色／深色主题。
