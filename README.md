## 下載與安裝

1. 到 [Releases](https://github.com/SkillGodAk/HGTV/releases) 下載最新的 `HGTV-版本-arm64.apk`。
2. 將 APK 傳到電視或盒子，使用系統安裝器安裝；首次安裝需允許該安裝來源。
3. 開啟 **HGTV**，完成版本檢查後即可瀏覽劇單。在「設定」選擇介面語言、外觀及播放偏好。

| 項目 | 支援範圍 |
| --- | --- |
| Android | Android 8.0 / API 26 以上 |
| 架構 | ARM64 / arm64-v8a |
| 操作 | 電視遙控器方向鍵、確認鍵、返回鍵；亦可觸控 |
| 語言 | 繁體中文、简体中文，切換後保存 |
| 外觀 | 亮色、暗色主題 |

Android 手機可用於輔助驗證；目前尚未完成所有 TV 型號與海外尖峰網路的實測。

| 情境 | 遙控器操作 |

| 首頁與集數頁 | 方向鍵移動焦點，確認鍵進入；向下瀏覽更多卡片 |

## 緩存與播放

目標是在緩存約 15% 的連續片段、取得影片索引並驗證解密資料後開始播放，後續繼續緩存。實際等待時間仍取決於片源與網路；不把百分比當作所有影片都能立即播放的保證。

TV 空間有限，緩存跟著集數回收：切集後刪除上一集，主要只保留當前播放與下一集預熱。緩存上限約 **64 MB**，剩餘空間不足時會縮小；不保存第二份完整解密影片。午夜清理只作殘留補清，Android 休眠可能延後排程，啟動 App 時也會補清。

來源失敗時會嘗試來源備援、重新取得網址或切換畫質。內容來源有時只返回一個網址，App 無法憑空增加有效 CDN 節點；海外晚高峰的改善仍需實際網路驗證。

## 劇集如何更新

**HGTV 版本更新**與**內容來源的劇集上新**是兩件事。劇單與選集透過內容接口取得，重新整理會重新讀取來源；首頁恢復時也會按刷新間隔更新。HGTV 不把劇集清單固定封存在 APK 裡，因此內容上新通常不需要另裝一個 APK。來源延遲、接口變更或故障仍可能影響顯示。

## 更新方式

開啟 App 會驗證本倉庫的簽章版本資訊。發布新版並提高最低可用版本後，舊版只能選擇 **立即更新**或**退出**，完成更新前無法進入首頁與播放。

下載的 APK 會核對 SHA-256、檔案大小、套件名稱、版本及安裝簽章；Android 系統仍需使用者確認安裝。若暫時無法驗證版本，入口會顯示重新檢查與退出，避免繞過強制更新。

**這是 APK 發布倉庫，不公開程式碼。** 倉庫只保存 APK 發布所需的版本資訊、LOGO、使用說明；程式碼、簽章私鑰與私人設定不放在 GitHub。
